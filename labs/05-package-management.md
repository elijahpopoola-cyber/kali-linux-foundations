# Lab 05 - Package Management

## Objective

This lab documents my introduction to package management in Kali Linux. I practiced using the APT package manager to check its version, view installed packages, and search for software packages.

## Commands Practiced

### `apt --version`

Displays the installed version of the APT package manager.

### `apt list --installed | head`

Displays the first few installed packages on the system.

### `apt search nmap`

Searches the available package repository for packages related to Nmap.

## Practical Evidence

I practiced these commands in my personal Kali Linux learning environment.

The `apt search nmap` command returned several packages related to Nmap and other tools containing or supporting Nmap functionality.

Screenshots are stored in the `screenshots` folder as evidence of this practical exercise.

## What I Learned

Through this lab, I learned that package management is important for managing software and security tools in Linux.

I also learned how to:

- Check the version of the APT package manager
- View installed packages
- Search for available software packages
- Identify packages related to a specific security tool

## Cybersecurity Relevance

Cybersecurity professionals often use package managers to install, update, and manage security tools. Understanding package management helps ensure that systems and tools are properly maintained.
